一、组织智能查询需求
1. 核心查询能力
建设一个基于离线组织基础库 + 关系库 + 标签库的组织智能查询 Agent，支持用户通过自然语言查询、筛选、关联和分析目标组织。
用户无需掌握固定查询语法，例如：
查询美国所有涉华智库
查询与美国国防部存在合作关系的情报外包机构
查询近5年参与涉台议题、且与FAPA存在关联的美国非政府组织
找出与某军工企业存在人员、项目或资金关联的高校
Agent 自动将自然语言转换为结构化查询条件，并返回符合条件的组织。
二、组织分类体系
建议建立一级组织类型 + 二级组织类型 + 业务标签三级体系。

五、组织—人员关系
与刚才的人员查询 Agent打通。
支持：
查询某组织现任负责人
查询曾任某政府机构、现任智库负责人的人员
查询某军工企业高管曾经任职的政府机构
查询某智库有哪些前美国政府官员任职
组织与人员之间建立：
任职、曾任职、创始人、负责人、董事、顾问、研究员、成员、发言人、捐赠人、合作人、联系人等关系。
这样就能实现：
组织 → 人员 → 组织 → 项目 → 事件
的关系穿透。

七、组织智能筛选
建议支持动态条件组合。
例如用户第一轮：
查询美国智库
系统：
组织类型 = 智库
国家 = 美国
返回 326 个组织。
用户继续：
筛选出与美国政府有人员交流的
系统自动继承上一轮条件：
组织类型 = 智库
国家 = 美国
AND 存在政府人员关联
用户继续：
再筛选涉及中国科技竞争的
变成：
组织类型 = 智库
国家 = 美国
AND 政府人员关联 = 是
AND 涉华领域 = 科技竞争

九、推荐的自然语言查询模板
最终可以让 Agent 支持这几类问题：
组织发现
美国有哪些涉华智库？
找出美国主要军工企业。
查询与关键矿产相关的美国企业。
条件筛选
从这些组织中筛选出与美国政府有合作关系的。
再筛选涉及台湾问题的。
排除纯商业机构。
关联查询
哪些组织与某智库存在合作？
某基金会主要资助哪些组织？
某组织有哪些政府背景人员？
时间查询
查询2024年以来涉华活动增加的智库。
查询近三年参与涉台议题的组织。
关系穿透
找出“美国政府 → 智库 → 基金会 → 高校”这条关系链上的组织。
十、最终可以形成一个统一的组织查询 Agent
整体逻辑建议设计成：
自然语言输入
↓
意图识别
↓
组织类型识别
↓
查询条件抽取
↓
条件组合 / 多轮继承
↓
组织基础库查询
↓
人员库 / 关系库 / 事件库关联查询
↓
组织画像生成
↓
组织列表 + 关系网络 + 风险标签
