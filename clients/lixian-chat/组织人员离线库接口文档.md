# 组织人员离线库接口文档

任务状态：`running`（进行中）→ `end`（正常结束） / `cancelled`（取消） / `failed`（失败）

---

### 一、新建会话接口

请求方式：POST  http://192.168.3.171:8088/api/chat/sessions

返回参数：

```json
{
    "createdAt": 1793607136102,
    "sessionId": "sess_58527fa3f6e445c79deda22e3c970486",
    "hermesSessionId": "api_1793607136_2a9f6a06"
}
```

说明：取 `sessionId` 给问答接口用。

---

### 二、问答

请求方式：POST http://192.168.3.171:8088/api/chat/ask

请求参数：

```json
{
    "sessionId": "sess_58527fa3f6e445c79deda22e3c970486",
    "userId": "u001",
    "message": "查询一下涉华美国智库"
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| sessionId | 否 | 不传则自动新建会话 |
| userId | 否 | 用户标识，写入历史用 |
| message | 是 | 提问内容 |

返回参数：

```json
{
    "sessionId": "sess_58527fa3f6e445c79deda22e3c970486",
    "hermesSessionId": "api_1793607136_2a9f6a06",
    "taskId": "task_a1b2c3d4e5f6478899aabbccddeeff00",
    "userId": "u001",
    "status": "running",
    "hint": "流式输出：GET /api/chat/tasks/task_xxx/stream"
}
```

说明：接口立即返回，`status` 为 `running`。取 `taskId` 去订阅流式、查任务或取消。

---

### 三、订阅流式输出（SSE）

请求方式：GET http://192.168.3.171:8088/api/chat/tasks/{taskId}/stream

Content-Type 为 `text/event-stream`。主要事件：（渲染思考过程和最终回答即可）

| event | 说明 |
|-------|------|
| connected | 订阅成功 |
| status | 任务状态，如 `{"status":"running"}` / `end` / `cancelled` / `failed` |
| reasoning.delta | 思考过程增量（中文） |
| assistant.delta | 最终回答增量 |
| tool.started / tool.completed | 工具调用起止 |
| cancelled | 任务被取消 |
| error | 失败信息 |
| stream_end | 本轮流结束 |

示例（片段）：

```text
event: connected
data: {"taskId":"task_xxx","sessionId":"sess_xxx"}

event: status
data: {"status":"running"}

event: reasoning.delta
data: {"delta":"用户要查涉华美国智库..."}

event: assistant.delta
data: {"delta":"根据检索结果..."}

event: status
data: {"status":"end"}

event: stream_end
data: {"ok":true}
```

### 四、取消任务

请求方式：POST http://192.168.3.171:8088/api/chat/cancel

按 taskId 取消：

```json
{
    "taskId": "task_a1b2c3d4e5f6478899aabbccddeeff00"
}
```

按 sessionId 取消该会话下所有进行中任务：

```json
{
    "sessionId": "sess_58527fa3f6e445c79deda22e3c970486"
}
```

返回参数：

```json
{
    "ok": true,
    "cancelledCount": 1,
    "skippedCount": 0,
    "cancelled": [
        {
            "taskId": "task_a1b2c3d4e5f6478899aabbccddeeff00",
            "sessionId": "sess_58527fa3f6e445c79deda22e3c970486",
            "statusBefore": "running",
            "cancelled": true,
            "status": "cancelled"
        }
    ],
    "skipped": []
}
```

说明：`taskId` 与 `sessionId` 至少传一个。取消后任务状态变为 `cancelled`，流里会收到 `cancelled` 与 `stream_end`。

### 五、历史记录（GraphQL）

请求方式：POST http://192.168.3.171:8088/graphql

调试页：http://192.168.3.171:8088/graphiql

示例：

```graphql
query {
  getChatHistory(
    userId: "test001"
    sessionId: "sess_58527fa3f6e445c79deda22e3c970486"
    keyword : ""
    pageNo: 1
    pageSize: 10
  ) {
    code
    message
    data
  }
}
```

说明：问答结束后会写入 ES；可用 userId / sessionId / taskId / keyword 查询历史。
